# @react-native-gpui/codegen

Generates the Rust and C++ code for desktop native modules and components from their TypeScript specs, as a plug-in for [`@react-native/codegen`](https://github.com/react/react-native/tree/main/packages/react-native-codegen).

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux.

You don't install this package yourself: `@react-native-gpui/core` depends on it, and the build runs it for the app and each library.
