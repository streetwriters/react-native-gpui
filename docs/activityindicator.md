All upstream props work as documented in the [React Native ActivityIndicator reference](https://reactnative.dev/docs/0.87/activityindicator). This page lists only what desktop adds or changes.

## Desktop props

None. This page has no props of its own on desktop.

## Differences

- The indicator is drawn in the style of each operating system: twelve fading spokes on macOS, a sweeping arc on Windows and Linux. A stopped indicator asks for no frames. The default color is the platform's secondary label color.
