## JavaScript Runtime

When using React Native, you're going to be running your JavaScript code in up to three environments:

- In most cases, react-native-gpui uses [Hermes](hermes), an open-source JavaScript engine optimized for React Native. Other engines can be installed as [packages](js-engines).
- Your code runs in the JavaScript engine of your app. There is no Node.js: Node built-in modules such as `fs` and `path` are not available.

While these environments are very similar, you may end up hitting some inconsistencies. It is best to avoid relying on specifics of any runtime.

### Internationalization (`Intl`)

Hermes provides `Intl.Collator`, `Intl.DateTimeFormat` and `Intl.NumberFormat`, `Intl.getCanonicalLocales`, `formatToParts`, and the locale-aware `toLocaleString`, `toLocaleDateString`, `toLocaleTimeString`, `toLocaleUpperCase`, `toLocaleLowerCase` and `localeCompare` methods. It has no `Intl.PluralRules`, `Intl.ListFormat`, `Intl.RelativeTimeFormat` or `Intl.Segmenter`.

The formatting data comes from the ICU library of the operating system. Nothing is bundled, so the app does not grow:

| Platform | Library                          | Minimum                                 |
| -------- | -------------------------------- | --------------------------------------- |
| macOS    | `libicucore`, part of the system | Every supported macOS                   |
| Windows  | `icu.dll` in System32            | Windows 10, version 1903                |
| Linux    | `libicu` (ICU 64 or later)       | Installed by most desktop distributions |

On Linux the engine uses the newest `libicui18n.so.N` it finds, from 100 down to 64. Set `RN_GPUI_ICU_VERSION` to use one version.

If no ICU 64 or later is found the app still starts. The engine logs one warning, `Intl` stays defined, numbers print as plain JavaScript numbers, dates print as ISO 8601 in UTC, strings compare by code unit, and upper- and lower-casing covers ASCII letters only.

## JavaScript Syntax Transformers

Syntax transformers make writing code more enjoyable by allowing you to use new JavaScript syntax without having to wait for support on all interpreters.

React Native ships with the [Babel JavaScript compiler](https://babeljs.io). Check [Babel documentation](https://babeljs.io/docs/plugins/#transform-plugins) on its supported transformations for more details.

A full list of React Native's enabled transformations can be found in [@react-native/babel-preset](https://github.com/react/react-native/tree/v0.87.1/packages/react-native-babel-preset).

## Polyfills

Many standard functions are also available on all the supported JavaScript runtimes.

#### Browser

- [CommonJS `require`](https://nodejs.org/docs/latest/api/modules.html)
- `md [console.{log, warn, error, info, debug, trace, table, group, groupCollapsed, groupEnd}](https://developer.chrome.com/devtools/docs/console-api)`
- [`XMLHttpRequest`, `fetch`](https://reactnative.dev/docs/0.87/network)
- [`{set, clear}{Timeout, Interval, Immediate}, {request, cancel}AnimationFrame`](https://reactnative.dev/docs/0.87/timers)

#### ECMAScript 2015 (ES6)

- [`Array.from`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/from)
- `md Array.prototype.{[find](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/find), [findIndex](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/findIndex)}`
- [`Object.assign`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/assign)
- `md String.prototype.{[startsWith](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/startsWith), [endsWith](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/endsWith), [repeat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/repeat), [includes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/includes)}`

#### ECMAScript 2016 (ES7)

- `md Array.prototype.[includes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/includes)`

#### ECMAScript 2017 (ES8)

- `md Object.{[entries](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/entries), [values](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/values)}`
