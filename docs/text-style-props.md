All upstream props work as documented in the [React Native Text Style Props reference](https://reactnative.dev/docs/0.87/text-style-props). This page lists only what desktop adds or changes.

## Desktop props

None. This page has no props of its own on desktop.

## Differences

- `fontFamily` accepts the generic families `system-ui`, `ui-sans-serif`, `ui-serif` and `ui-monospace`, and families loaded with [Fonts](desktop-fonts).
- `fontVariationSettings` does not exist in React Native 0.87 and is not supported.
