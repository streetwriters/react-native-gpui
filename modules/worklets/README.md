# @react-native-gpui/worklets

GPUI platform bindings for react-native-worklets

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux. The package adapts `react-native-worklets`: version `0.13.0` goes with `react-native-worklets` 0.13.x. It needs React Native 0.87.x.
