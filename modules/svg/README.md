# @react-native-gpui/svg

GPUI Fabric renderer adapter for react-native-svg

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux. The package adapts `react-native-svg`: version `15.15.0` goes with `react-native-svg` 15.15.x. It needs React Native 0.87.x.
