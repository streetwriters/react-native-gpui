# @react-native-gpui/gesture-handler

Native GPUI gesture recognition for react-native-gesture-handler

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux. The package adapts `react-native-gesture-handler`: version `3.3.0` goes with `react-native-gesture-handler` 3.3.x. It needs React Native 0.87.x.
