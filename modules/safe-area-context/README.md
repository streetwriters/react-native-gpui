# @react-native-gpui/safe-area-context

GPUI platform implementation for react-native-safe-area-context

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux. The package adapts `react-native-safe-area-context`: version `5.10.0` goes with `react-native-safe-area-context` 5.10.x. It needs React Native 0.87.x.
