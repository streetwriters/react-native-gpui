# Changelog

All notable changes to `@react-native-gpui/pdf` are listed here. Each version's section becomes the notes of its GitHub release.

## Unreleased

- First version, a spike: runs EmbedPDF's own engine (`@embedpdf/engine`, unchanged) on EmbedPDF's native PDFium runtime, loaded as the Node-API addon that `@embedpdf/engine-runtime-<platform>` ships. No WebAssembly and no Web Worker.
- `@react-native-gpui/pdf/metro.cjs` wraps a Metro config so `@embedpdf/engine` uses the native runtime: it swaps `@embedpdf/engine-runtime`, picks the Node inline transport, leaves the WebAssembly glue out and turns `import.meta` into a constant for EmbedPDF packages.
- Native page tiles: with a `tiles` sink, `image()` hands the rendered bitmap's native pointer to the sink and returns an 8-byte token instead of pixels, so no pixels enter JavaScript.
- `THIRD_PARTY_NOTICES.md`, generated by `scripts/generate-notices.mjs` (run on `prepack`) from the runtime repository and the components it builds.
- The runtime is the first `@embedpdf/engine-runtime-<platform>` addon that loads, instead of a guess from the platform, which has no architecture on desktop.
- Native tile store (`NativePdfTiles`) and the `PdfTile` view: bitmaps are adopted into gpui textures under a byte budget (192 MiB by default, `setBudget`), least recently used first; tiles on screen are never evicted and evicted textures are released from the GPU.
- `createPdfEngine` registers EmbedPDF's default Hebrew and Arabic fallback fonts (`fallbackFonts: false` to skip); await `engine.fontsReady` before opening a document.
- `PdfViewer`: a virtualised, continuous page view whose pages are drawn from the render plugin's tile plan by native `PdfTile` views, with zoom (in, out, fit width, fit page), page navigation, an unlock flow and download, driven through a controller ref.
- Tile handles report the size of the bitmap they stand for, so the render plugin's raster store evicts them like pixel data.
- Fix: the module no longer defines `crypto.getRandomValues`. `createPdfEngine` throws when the app has not installed a secure one, and `queueMicrotask` and `performance.now` are only added when missing.
