# @react-native-gpui/screens

GPUI platform integration for react-native-screens

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux. The package adapts `react-native-screens`: version `4.28.0` goes with `react-native-screens` 4.28.x. It needs React Native 0.87.x.
