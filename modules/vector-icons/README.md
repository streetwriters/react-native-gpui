# @react-native-gpui/vector-icons

Desktop support for [`@react-native-vector-icons`](https://github.com/oblador/react-native-vector-icons): icon glyphs rasterized by the desktop renderer.

Part of [react-native-gpui](https://github.com/streetwriters/react-native-gpui), React Native for macOS, Windows and Linux.

## Install

Install it next to the icon sets you use:

```sh
npm install @react-native-vector-icons/material-design-icons @react-native-gpui/vector-icons
```

Use the icon components as on iOS and Android; nothing else changes.
